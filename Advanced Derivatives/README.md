## Assumptions and choices to review

- **FinancePy 1.1.x** names the functions `value`/`delta`/`gamma`, not `bs_value`/`bs_delta`/`bs_gamma`. The import handles both versions.
- **Q1(b):** the brief says "4 elements" but lists 5; we return all 5. Realised variance is the annualised sum of squared log-returns.
- **Q1 numbering:** the PDF brief repeats 1(g) as 1(h). Our 1(h) is the drift question, which is 1(i) in the brief.
- **Q3(f):** "T0 = 0" is read as averaging starting today, daily over 180 days. The original contract (T0 = 3m, 90 days) is shown as well. The control uses the **exact discrete** geometric price, not the continuous Kemna–Vorst formula, which would bias the estimate.
- **Q3(g):** the theory gives only 2–8 paths because ρ > 0.999. The report says that in practice you would still use a few hundred.
- **Q4** uses the 3(e) market data on the original contract (T0 = 3m) with P = 10,000.
